# al1-surrogate-web

A web UI for surrogate model applications. This project provides an interactive interface for surrogate model operations, built with JavaScript, Python, HTML, and CSS.

## Overview

al1-surrogate-web is a full-stack web application designed to serve as a user interface for surrogate model systems. It combines frontend technologies with Python backend capabilities to deliver a seamless user experience.

## Technology Stack

- **Frontend**: JavaScript (32.1%), HTML (19.5%), CSS (17.9%)
- **Backend**: Python (30.5%)

## Features

- Interactive web interface for surrogate model interaction
- Full-stack architecture for robust performance
- Responsive design with CSS styling
- Python backend for complex computations

## Getting Started

### Prerequisites

- Node.js and npm (for frontend dependencies)
- Python 3.x (for backend dependencies)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/o0muay72670o/al1-surrogate-web.git
cd al1-surrogate-web
```

2. Install frontend dependencies:
```bash
npm install
```

3. Install Python dependencies:
```bash
pip install -r requirements.txt
```
